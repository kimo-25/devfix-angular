# DevFix Angular UI

واجهة Angular 18 عربية RTL تغطي شاشات الـ Feature Matrix الخاصة بمنصة صيانة الأجهزة.

## التشغيل
1. ثبّت Node.js إصدار LTS.
2. فك ضغط المشروع وافتح Terminal داخل المجلد.
3. شغّل:
   ```bash
   npm install
   npm start
   ```
4. افتح الرابط الذي يظهر غالبًا `http://localhost:4200`.

## الشاشات الموجودة
- العميل: الرئيسية، الدخول، الأجهزة، تفاصيل الجهاز وسجل الصيانة، البحث والفلترة، ملف مركز الصيانة والفني، إنشاء طلب، مقارنة العروض، تفاصيل الطلب ومراحل الإصلاح، محضر استلام الجهاز، خيارات التسليم والمواعيد، الفاتورة، الشكاوى، التقييمات، الضمان وسياساته، المحفظة، الحساب، الإشعارات والخصوصية، مركز المساعدة، دليل المصطلحات، صفحة عن المشروع ودراسة السوق والمنافسين، وصفحة 404.
- مركز الصيانة: لوحة مؤشرات المركز، التسجيل، الطلبات المتاحة، الطلبات الجارية، الخدمات والأسعار، التقييمات، المحفظة، معاينة تجهيز عرض سعر، وتحديث مراحل الإصلاح.
- الإدارة: لوحة مؤشرات ورسوم بيانية، نماذج حالات الواجهة (تحميل/فارغ/خطأ)، مراجعة المراكز وملفات التسجيل، العمليات والنزاعات، المالية، التقارير، دعم العملاء، الأمان، الأدوار والصلاحيات.
- اختصارات تربط خطوات العميل والمركز والإدارة بالشاشات المكملة، مثل مقارنة العروض ومتابعة الإصلاح ومراجعة المركز.

## ملاحظات مهمة
- هذا **Frontend UI Prototype** ببيانات تجريبية.
- لا يوجد Backend أو API أو قاعدة بيانات أو مصادقة فعلية.
- أزرار الإجراءات تعرض رسائل توضيحية أو تغيّر حالة الواجهة محليًا فقط.
- اختيار الملفات تجريبي، ولا يتم رفعها إلى خادم.
- صلاحيات الموظفين المعروضة توضيحية وليست نظام حماية فعليًا.
- الواجهات متجاوبة مع الشاشات الصغيرة، مع احتواء الجداول العريضة داخل مناطق تمرير خاصة بها.
- يمكن تعديل الألوان والمحتوى في `src/app/page.component.ts` وملفات CSS.
- الشاشات الإضافية للعرض موجودة في `src/app/showcase.component.ts`، وتستخدم بيانات ثابتة دون عمليات خلفية. المسارات غير المعروفة تعرض صفحة 404 تجريبية.
